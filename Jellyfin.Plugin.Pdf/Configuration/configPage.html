Controls the quality of generated PDF thumbnails. Higher values produce sharper images but increase processing time. Valid range: 36–1000. Default: 90.
Controls the background fill used when squaring the thumbnail. White padding works best for JPEG covers; transparent preserves the page background; no padding keeps the original page proportions.
"Skia only" uses Jellyfin's built-in encoder (no extra dependency). "Skia + ImageSharp" adds WebP encoding method and near-lossless controls. Rendering always uses Skia; only the final encode step changes.
The image format used to encode the generated cover. PNG and WebP support transparency; JPEG does not.
Lossless keeps every pixel (typically ~20–30% smaller than PNG); lossy trades quality for much smaller files.
Compression method (0–6). Higher values produce smaller files, more slowly, with no extra quality loss. Only available with the "Skia + ImageSharp" engine. Default: 4.
Effort for lossless encoding (PNG / WebP lossless). Higher values produce smaller files, more slowly, with no quality loss. Valid range: 0–100. Default: 100.
Pre-processes the image to compress further with minimal, usually invisible, quality loss. Only available with the "Skia + ImageSharp" engine for lossless WebP.
Visual quality for lossy encoding (WebP lossy / JPEG). Lower values produce smaller files with more visible artifacts. Valid range: 1–100. Default: 90.
Trades JPEG color detail for file size. 4:2:0 is smallest; 4:4:4 keeps full color resolution. 4:2:2 is only supported by the "Skia only" engine (the ImageSharp engine falls back to 4:2:0).
Caps the longest side (in pixels) of the generated image. The limit only ever reduces the image, never enlarges it. "No limit" keeps the resolution defined by the render DPI.
Enter a custom maximum for the longest side. Valid range: 200–20000 px.
